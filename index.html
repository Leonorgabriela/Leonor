MODELO MATEMÁTICO

¿Cómo se calcula?

dI/dt = −v

El inventario disminuye de acuerdo con la cantidad de productos vendidos.

I(t) = I₀ − vt

Para una tasa de ventas constante, esta ecuación permite representar cómo cambia el inventario con el paso del tiempo.

t = I₀ / v

Con esta expresión se obtiene el tiempo estimado para que el inventario llegue a cero.

La tasa de venta se obtiene a partir de los registros de ventas almacenados en el sistema.
